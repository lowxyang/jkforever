# Guest passwords

Add one guest per line: their name, a vertical bar, then the password they should type.

# Example: Aunt May | garden

Blank lines are ignored. A line that starts with # is a note, not a password.

Edit this file on GitHub, then commit the change. The live site reads this list, so new passwords start working after the page is refreshed. The repository is public, so anyone who can open this file can read the codes.
